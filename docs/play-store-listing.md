# ConcreteMix Pro Play Store Draft

## App Name

ConcreteMix Pro

## Short Description

Concrete quantity, mix ratio and cost calculator for onsite work.

## Full Description

ConcreteMix Pro is a fast, offline-first concrete calculator for contractors, builders and owner-builders.

Estimate concrete volume, wet and dry quantities, cement bags, sand, aggregate, water, additives and material costs directly on your phone. The calculator is designed for practical onsite use with large controls, instant recalculation and local project storage.

Use ConcreteMix Pro for slabs, beams, columns, footings, driveways, paths, foundations and ready-mix volume estimates.

Key features:

- Concrete volume calculator
- Metric and imperial units
- Purpose-based strength and mix suggestions
- Custom mix ratios
- Ready-mix cost option
- Cement bag estimates
- Sand, aggregate, water and additive estimates
- Material cost calculator
- Saved projects and locations
- PDF estimate and order-list export
- Local backup export/import between devices
- Built-in help guide
- Works offline after installation
- No login, no cloud account and no backend

ConcreteMix Pro is a practical estimating tool. Final structural concrete mixes, reinforcement, design strength and compliance requirements should be confirmed with local specifications, supplier data or a qualified professional where required.

## Data Safety Draft

- Data collected: No data collected by the developer.
- Data shared: No data shared by the developer.
- Account required: No.
- Users can delete local saved projects/settings inside the app data controls.
- App stores projects, notes, material prices and settings locally on the user's device/browser storage.
- Users can export a local JSON backup file and import it on another device. The user controls how that file is moved or shared.
- PDF files are created only when the user chooses Save or Share.
